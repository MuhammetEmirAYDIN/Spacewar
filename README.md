
# SPACEWAR

Space war is my full-fledged first game that was developed using C# and Raylib, It is a game where players control a spaceship and battle against enemies in space.


-------

## 🚀 Features

Fast-paced combat with spaceship controls for movement and shooting.

Multiple enemy types, each with unique behavior and attack patterns.

Game-over screen with score tracking and final results.

Smooth and responsive controls, allowing the player to move and shoot with ease.

-----

## 🎮 Gameplay Instructions
    **Move**: Use the WASD keys to move your spaceship around.

    **Shoot**: Press or hold the left mouse key to shoot bullets at enemies.

    **Objective**: Defeat all enemies and survive for as long as possible to achieve a high score.

    **Game Over**: The game will end when your spaceship's health reaches zero. Try to beat your high score!
